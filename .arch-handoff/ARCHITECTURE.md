# Модель с нуля: собственный претрейн → SFT → RL → MOPD с механическим вердиктом _(черновик, не подтверждён)_

> Источник истины: `.arch/solution/SOLUTION.json`. Черновики механики и агента помечены; подтверждает человек.

## 1. Что и зачем

- **Зачем:** Нужна собственная нейросеть с нуля (свои веса и свой конвейер обучения), а не адаптация чужих весов; паритет с Kimi K3 по масштабу арифметически недостижим (2,8T/104B, 20–40T токенов, 10–20M H800-ч, ~$20–40M на прогон), поэтому предмет доказывания — узкая объявленная ось: архитектурные задачи собственного контура с механическим фитнес-вердиктом при равном бюджете рассуждений и общем харнессе. _(черновик, не подтверждён)_
- **Ожидаемый результат поставки:** Скелет L3 проходит конвейер целиком (чекпойнт → инференс на Spark → RL-среда → SFT → RL) и закрывает гейт A4; на объявленной оси дельта пройденных fitness-гейтов ≥ +5 п.п. против baseline K3 при holdout n ≥ 200, не использованном в SFT/RL; повторный прогон по манифесту даёт тот же вердикт (NFR-002). _(черновик, не подтверждён)_
- **Заказчик:** —
- **Инкремент:** Walking skeleton L3: ~1B MoE (LatentMoE-минимум: latent 0,5×hidden, 12 routed + 2 shared, top-2 + shared, QB) / 20B токенов, ~97 H800-ч, ≈$200 — весь конвейер до масштабных трат; масштабный класс L1/L1+ не выбирается. _(черновик, не подтверждён)_
- **Объект управления:** Конвейер обучения и собственная модель: данные и токенизация (CMP-001), претрейн-конвейер и аренда GPU (CMP-002, INT-001), пост-тренировка SFT → RL → MOPD (CMP-003), инференс-рантайм на DGX Spark (CMP-004), RL-среда и верификаторы (CMP-005), агентный харнесс (CMP-006). _(черновик, не подтверждён)_

## 2. Границы

Входит _(черновик, не подтверждён)_:
- Данные и токенизация: дедупликация, фильтрация качества, собственный BPE 160K, карточка датасета с sha256 (CMP-001)
- Претрейн-конвейер L3-скелета: JAX + форк MaxText, KDA собственная реализация, Muon/NS, QAT MXFP4 со стадии SFT (CMP-002)
- Пост-тренировка: SFT → RL со групповым преимуществом и log-ratio-маской → MOPD-консолидация, минимум 2 домена × 2 уровня усилия (CMP-003)
- RL-среда и верификаторы v1: task spec, публичный и скрытый верификаторы, детерминированная награда, run manifest (CMP-005)
- Агентный харнесс, общий для baseline K3 и собственных чекпойнтов (CMP-006)
- Инференс-рантайм на DGX Spark: 4-битная квантизация, контекст 1M в 128 ГБ unified (CMP-004)
- Сравнительный стенд против K3 на объявленной оси (отчётность, не стадия рецепта)

Явно не входит _(черновик, не подтверждён)_:
- Паритет с K3 по масштабу (2,8T/104B, 20–40T токенов, 10–20M H800-ч, ~15 МВт, капекс $400M+)
- Продуктовая монетизация и лицензионный режим Kimi K3 License §2–3
- Выбор масштабного класса L1 (≈$44k) / L1+ (≈$117k) — отложен владельцем до результатов скелета
- Чужие веса как основа: адаптация предобученной модели вместо своего претрейна
- LLM-судья в контуре награды RL (AD-2)
