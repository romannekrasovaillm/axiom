# Дельта: mfu-g1-kda-solve
- Route: Standard
- Created: 2026-10-09
- Владелец: архитектор. Основание: ADR-050 (гейт G1), ADR-047 (математика KDA неизменна, реализация заменяется), G0-адрес (`evidence/mfu-55/G0b/REPORT.md`).

## Проблема

G0 показал: шаг `chunked_cc` — «шторм мелких ядер» (493 173 запуска за 120 с, занятость GPU 5.1%), доминируют LU-ядра `getrf_panel`, `batch_trsm_left_kernel`, `LuPivotsToPermutation` — по 34 560 запусков каждого. Источник в коде: **`net/kda.py`, `cc_chunk_step`: `t_mat = jnp.linalg.inv(eye + l_mat)`** — инверсия единичной нижней треугольной `(H, C, C)` на каждый чанк × голову × слой через LU (`getrf`+`getri`), плюс `wyut`-путь тем же способом. Математика требует лишь решения систем `(I+L)·W = diag(β)ΓK` и `(I+L)·U = diag(β)V`, а не обращения матрицы.

## ADDED

- When контур вычисляет KDA-чанк, the реализация shall решать треугольные системы **батчево** (`jax.lax.linalg.triangular_solve` или явная прямая подстановка через `lax.scan`) вместо `jnp.linalg.inv` — без построения обратной матрицы и без LU-разложения на каждую голову/чанк.
- Паритет с recurrent-оракулом сохраняется побитово-в-допуске: тесты `net/tests/test_kda_chunked_cc.py` (+ родственные WY/UT) зелёные с существующими константами `atol`.

## MODIFIED

- `net/kda.py` — реализация `cc_chunk_step` (и, при той же математике, WY/UT-путь, если он использует ту же инверсию); публичные сигнатуры и семантика `kda_impl` не меняются.

## REMOVED

- Ничего: прежняя форма остаётся достижимой (флаг `kda_impl` / `git revert`) — критерий отката.

## План отката

`git revert` коммита правки; признак регрессии — падение тестов паритета или рост loss на 20 шагах против контрольной руки.

## Критерии приёмки (G1, измеряются на GB10 отдельным прогоном)

- [ ] паритет: `net/tests/test_kda_chunked_cc.py` + WY/UT-тесты зелёные;
- [ ] профиль шага: запусков ядер **≤ 2 000** (с 493 173), хост-синхронизаций **≤ 5 000** (с 113 895+22 399);
- [ ] занятость GPU **≥ 40%** (с 5.1%), **MFU ≥ 3% = 977 ток/с** (базовая конвенция `6·N_active`; baseline 532.8);
- [ ] `L3a KDA ≥ 20% MFU` — долг ADR-047 закрыт;
- [ ] loss за 20 шагов не хуже контрольной руки; первый шаг вне KPI.
