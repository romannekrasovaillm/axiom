# Дельта: privacy-paths
- Route: Standard
- Created: 2026-10-09
- Владелец: архитектор. Основание: обнаруженная утечка локальной фактуры в UI/внешние сервисы — абсолютные домашние пути в артефактах кейса.

## Проблема

В отслеживаемых артефактах кейса лежали **абсолютные домашние пути** `<HOME>/...` — 23 файла, включая `README.md`, `docs/RUNBOOK-GB10.ru.md`, `docs/adr/ADR-020`, `ADR-044`, `ADR-051`, `model/sensors.yaml`, `docs/reviews/*`, handoff-пакет `.arch-handoff/*` и планы флота `.arch-fleet/*.plan.toml`. Такая строка раскрывает имя пользователя и структуру домашнего каталога везде, где артефакт показывается или отправляется: в UI (панели чата/веб-клиентов), в отчётах, в handoff-пакетах к внешним агентам. Контур это не ловил: правила приватности (C-021) закрывали только вывоз корпуса, но не гигиену путей.

## ADDED

- **C-054** «Гигиена приватности: в артефактах кейса нет абсолютных домашних путей» — `must_not_contain`, glob `**/*.{md,json,yaml,yml,toml}`, pattern `/(home)/(roman|nekrasov)[a-z0-9_-]*/`, `exclude_glob`: `evidence/**`, `env/**`, `net/tests/**` (машинные журналы и тестовые фикстуры вне набора), severity high, owner/expiry заполнены.
- Запись `C-054` в реестр наследования `model/rule-lineage.yaml` (`none` + причина: правило механическое, смысл проверяется им самим) — иначе контур валит `claims --verify-layer` («documentary не покрыто реестром»).

## MODIFIED

- `.arch-handoff/CONSTRAINTS.yaml` синхронизирован с корневым (иначе `registry_diverged`).
