# Кейс «axiom» — модель с нуля против Kimi K3

Паспорт кейса. Точка входа для исполнителя: здесь цель, рамки, состав пакета и гейты.

## Цель и артефакт

Собственная нейросеть **с нуля**: полный претрейн + пострейн (SFT → RL по схеме базы → MOPD) + агентные способности, с собственным конвейером обучения. Не адаптация чужих весов.

## Что и почему так

| Вопрос | Ответ |
|---|---|
| Масштаб | Решением владельца 2026-09-11 сначала **скелет L3** (1B / 20B токенов, ≈$200). Класс L1 (≈$44k) / L1+ (≈$117k) — **OPEN**, решение после результатов скелета |
| Почему не паритет с K3 | 2,8T/104B активных, 20–40T токенов → 10–20M H800-ч (~$20–40M) на один прогон, ~15 МВт, капекс $400M+. Другой класс затрат, не архитектурная задача |
| Архитектурная база | Опубликованный дизайн K3 (KDA + AttnRes + LatentMoE + SiTU-GLU), пиннинг на `k3_tech_report.pdf`; своя новизна — данные, пострейн, харнесс |
| Почему KDA | 1M контекста не влезает в 128 ГБ Spark с классическим KV-кэшем ни при какой квантизации |
| Модальности v1 | Принято 2026-09-11: нативные text + image + video, как у K3; скелет L3 включает минимальный визуальный путь |
| Источники траекторий | Принято 2026-09-11: сторонние модели допускаются с фиксацией лицензии и источника в карточке датасета |
| Ось победы | Принято 2026-09-11: задачи с фитнес-гейтом (артефакт репозитория против механических правил); равный бюджет, общий харнесс. Паритет на общих бенчмарках не заявляется |
| Первый срез | Walking skeleton L3: **~1B MoE (LatentMoE-минимум: latent 0,5×hidden, 12+2 эксперта, top-2+shared, QB) / 20B токенов, ≈$200** — весь конвейер до среды до масштабных трат (решение владельца 12.09: MoE вместо dense — доказывать инновацию базы на скелете) |
| Стек реализации | Принято 2026-09-12 (вечер): JAX + форк MaxText (ADR-008, supersede ADR-007 PyTorch) — Muon/MuonClip, MTP, GRPO/GSPO (Tunix), K2-семейство поддержано; KDA — своя реализация (JAX+Pallas, referенс → кернелы); QAT MXFP4 — своя fake-quant/AQT |

## Состав пакета

- `docs/adr/ADR-001…008` — масштаб и ось; RL-среда и верификаторы; архитектура и исполнение на Spark; конвейер претрейна; пост-тренировка; домен оси победы; стек (ADR-007 PyTorch superseded → ADR-008 JAX/MaxText).
- `ARCHITECTURE-SPINE.md` — AD-1…AD-8 (ось, механический вердикт, единый контракт прогона, пиннинг, архитектурная база, приватность, ресурсы GB10, лимит стоимости).
- `CONSTRAINTS.yaml` — 31 механическое правило (C-001…C-031), проверяются без LLM.
- `model/` — типизированная модель: REQ-001, CAP-001, NFR-001…006, AD-1…8, CMP-001…006, INT-001.
- `docs/research/k3-tech-report-extract.md` — извлечение первоисточника `k3_tech_report.pdf` (`pdftotext -layout`, 3168 строк) с построчными ссылками `:NNN`; основа матрицы верности.
- `docs/FIDELITY-TO-K3.md` — матрица верности: что раскрыто, что нет, что входит в скелет L3.
- `docs/axiom.architecture.json` + `docs/axiom-architecture.html` — Archify-снапшот архитектуры (architecture-as-code, self-contained HTML).
- `docs/specs/ENVIRONMENT-V1.md` — спецификация RL-среды environment v1: task spec, верификаторы (arch-ml CLI), детерминированная награда, run manifest, лесенка сложности, кальбровка K3 как precondition RL.
- `docs/specs/MODEL-L3-SKELETON.md` — спека сети с нуля (скелет L3): конфиг 1B dense (18 KDA + 6 Gated MLA, NoPE, MTP, ViT-минимум), оракулы паритета (FLA/MaxText-K2), QAT MXFP4 со стадии SFT, данные (претрейн публичный, SFT/RL — gb10-shared), 10 механических критериев приёмки.
- `docs/DECISION-PACKAGE.json` — пакет решения для A3 (choice, constraints, rejected, expiry 2026-09-25).

## Формат задачи RL-среды (environment v1)

`id`, `prompt`, `workspace`, `verifier`, `budget_seconds`, `max_tokens`, `thinking_budget`, `attempts`; результат — детерминированный вердикт + run manifest (снапшоты, параметры, токены, стоимость). Полная спецификация: `docs/specs/ENVIRONMENT-V1.md`. Стыковка сети со средой: `env/net_executor.py` (адаптер по образцу `env/stub_model.py`: токенизация BPE → `net/infer.py` → ответ → verifier → манифест; end-to-end тест — `net/tests/test_13_integration.py`).

## Гейты

| Гейт | Что проверяется | Критерий прохождения |
|---|---|---|
| A3 (сейчас) | бюджет и масштабный класс | явное решение человека, срок 2026-09-25 |
| A4 | conformance: skeleton L3 воспроизводит конвейер и проходит среду и стенд | зелёный скелет: чекпойнт → инференс на Spark → RL-среда → SFT → RL по схеме базы |
| A5 | drift: повторный прогон по манифесту даёт тот же вердикт | совпадение вердикта, пиннинг снапшотов |

## Открытые вопросы

1. Закрыто 2026-09-12 (ADR-006, решение владельца): домен оси победы — архитектурные гейты собственного контура (fitness/trace/spine arch-ml без деградации); RL-среда в скелете разблокирована (CMP-005, CMP-006). Precondition запуска RL — кальбровочный прогон K3 на лестнице сложности.
2. Бюджет аренды и масштабный класс (L1 / L1+) — сознательно отложен владельцем до результатов скелета L3; дедлайн пакета A3 — 2026-09-25 (`docs/DECISION-PACKAGE.json`). Мультимодальность в v1 (NFR-006) делает смету 22k H800-ч нижней границей — пересчёт перед выбором класса.
3. Закрыто 2026-09-11: первоисточник прочитан (`docs/research/k3-tech-report-extract.md`); неполнота источника зафиксирована в `docs/FIDELITY-TO-K3.md` — отчёт K3 не раскрывает абсолютных вычислений, суммарного числа токенов, гиперпараметров RL и долей данных; эти места закрываются нашими решениями с пометкой «наше».
