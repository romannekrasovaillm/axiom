# MODEL-STAIRS — лестница моделей прототипирования

- Date: 2026-10-06
- Status: Accepted (архитектор; реализация запроса владельца «лесенка моделей для быстрого прототипирования»)
- Связь: ADR-035 п.3 (микро-лесенка RL-задач — отдельная проработка), VERIFICATION-LEG (124M-ступени), AD-4 (proto-прогоны вердиктов не несут)

## Принцип

Прототипирование (тесты фич конвейера, смоуки, отладка детерминизма, A/B-механика) выполняется на **нижней достаточной ступени**; полная модель — только для экспериментальных прогонов, несущих KPI/вердикты. Каждая ступень — декларативный конфиг `net/config-proto-*.json`; раннер: `tools/pretrain_run.py --config-path <файл>` (или run_sft_smoke для SFT-смоков). Пин токенизатора v2 и KPI-пины на proto-ступени **не распространяются**: их словари — тестовые, прогоны вердиктов не несут (AD-4 применяется к KPI/вердиктным прогонам).

## Правила

1. **Диагностические ступени (proto-*) вердиктов не несут**: pass_rate/PPL/proto-прогоны — справочные; KPI-пины (C-046) на них не пиннуются.
2. Токенизатор proto-ступеней — тестовый словарь; смена словаря proto-конфига не требует ADR (это не канон токенизатора).
3. Новая ступень — новый конфиг-файл + строка в этой таблице; замороженные пресеты (`small`, `tiny`) не расширяются.
4. Прототипирование всегда начинается с минимальной ступени, достаточной для тестируемого свойства; подъём по лестнице — только если свойство зависит от масштаба.

## Проверка лестницы

Смоук proto-micro — **исполнен 07.10**: конфиг валиден Config-валидацией, 5 шагов end-to-end на CPU стенда (JAX_PLATFORMS=cpu, ~80 с/шаг с jit), метрики+чекпойнт записаны (`axiom-run/verification-leg/proto-micro-smoke/`). Dense-124M смоук (GPU): 50 шагов, медиана 324 ток/с — факт для вердикта verification-leg (MFU ~2-3% на нетюнинге; сравнение с arch-124M при равном бюджете — следующий шаг).
