## Принятые состояния (не «починить», а зафиксировать)

- **Контейнмент D→K — монитор no-op**: премиса вложения опровергнута измерением (96 217×5 658 → 0 пар, max оконный Jaccard 0.3524); ступень остаётся непрерывным метром пересечения.
- **Карточки K без `level` включены** (10 466 шт.); 5 экзотических уровней (advanced/core/meta) — в корпусе, отмечены.
- **Near-dup LSH-коллизии** (кандидаты 4 365 → снято 179, re-дедуп выхода 0/0) — известное поведение полос, второе точное сравнение страхует.
- **Красный стендовый гейт** — известное состояние до O-1/O-2 (см. выше); anti-weakening не нарушен ни одной дельтой (проверено delta_guard + воспроизведением на baseline).
- **Верификация verified-partial** — в SFT с флагом (1 эпизод на текущей пересборке); SUITE_RED_RE ловит строчные итоги pytest.

## Требует проверки фактов (не решено по первоисточникам)

- **QAT MXFP4**: «своя fake-quant либо AQT» — сравнение подходов не завершено (`[ТРЕБУЕТ ПРОВЕРКИ]` из DECISION-PACKAGE); до SFT-стадии L1 — выбрать и зафиксировать ADR.
- Гипотеза «narrow-deep стабильнее для multi-hop» — StepFun-обоснование, собственный вердикт появится только на L1-A/B.
