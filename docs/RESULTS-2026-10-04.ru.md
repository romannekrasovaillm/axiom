# Отчёт 04.10.2026: стена памяти l3-full снята — пилот исполняется на GB10; RL-стадия пересажена на arch-ml (ADR-022)

Сессия «прокачка GB10 по всем стадиям + RL на самом Spine AI/ML». Итог дня:
блокер 03.10 (l3-full @ T=8192 просил ~890 ГиБ) **снят тремя дельтами памяти** —
пилот l3-full прошёл гейт токенизатора v2 и исполняет шаги на стенде. Рецепт
RL-стадии зафиксирован решением владельца в ADR-022 (среда и верификатор — сам
arch-ml; онлайн-синтез сред по FrogNano; практики Laguna).

## Синхронизация стенда

- Стенд `gb10-fast:~/axiom` дотянут до `main` (`6645667`) git-bundle'ом (прямой
  fetch с GitHub на стенде рвётся). Незакоммиченная рабочая копия дельт на
  стенде оказалась байт-эквивалентной main (diff — только отсутствующие
  тесты/доки); `git reset --hard` потерь не дал.
- Токенизатор v2 (`16e4a532…`, BPE 160K + русский корпус): packed-токены уже
  лежали на каноническом диске — `~/gb10-shared/datasets/axiom-pretrain-l3/tokens-v2`
  (W 13,95B + C 3,14B + Q 0,86B ≈ **17,95B токенов**, T=8192, манифесты с полным
  sha256). Перепаковка НЕ понадобилась — утренний прогон её завершил.
- Гейт полного хеша (`6645667`) подтверждён боем: пилот прошёл проверку
  `tokenizer_hash` артефакт↔манифест (вчерашний отказ 10:08 был дефектом
  обрезанного префикса, починен).

## Вердикт по блокеру: l3-full @ T=8192, vocab 160k — ВЛЕЗАЕТ

Прогон `pretrain-pilot-gb10` (журнал `~/axiom-run/pilot-l3full-journal.jsonl`,
метрики `~/axiom-run/pilot-l3full/metrics.jsonl` на стенде): пресет **l3-full**,
T=8192, B=1, `grad_ckpt_policy=per_layer`, `ce_chunk_tokens=1024`,
`kda_chunked_backward=true`, `scan_layers=true` — все дельты памяти включены.

**Нога-вердикт завершена: `status=executed`, 30 шагов, 245 760 токенов,
loss 13,54 → 10,76, `tree_hash=f0e27e4c76095207…`, остановка «по плану».**

- Компиляция (шаг 1): 881 с; далее **~102–118 с/шаг**, 65–82 токенов/с
  (0,21–0,24 TFLOPS achieved; MFU-подсчёт — отдельно).
- Память хоста стабильна: 113/121 ГБ, доступно ~8 ГБ; earlyoom молчит
  (`journalctl -u earlyoom` пуст). GPU-пул 0,6 × 121 ГБ + PREALLOCATE=false.
- Сравнение с 03.10: граф требовал ~890 ГиБ при любой remat-политике; теперь
  исполняется в пуле ~72 ГиБ. Ключевые дельты: chunked CE (`b0f29dc`),
  chunked backward KDA (`1e621c0`), group-scan (`940dcd0`+`273d609`).
- Чекпойнты: `--checkpoint-every` по умолчанию 0 — нога-вердикт чекпойнт не
  писала (не требовалось); endurance-нога запущена с `--checkpoint-every 25
  --ckpt-every-min 30 --stop-file ~/axiom-run/STOP` (300 шагов ≈ 9 ч,
  продолжение `--resume`-ногами; свежий старт: `--resume` на пустом каталоге
  честно отказывает — fail-closed).
- Грабли запуска, зафиксировано: `--resume` без существующего чекпойнта —
  отказ («ОТКАЗ: нет чекпойнтов»), не свежий старт.

Известные предупреждения прогона (оба by design, оба в журнале):
`tokenizer.matches_canonical=false` (корпусный BPE v2 ≠ модельного 9f8d0309 —
механика override существующая, см. test_pretrain_tokenizer_override.py;
закрывается предстоящим ADR-004-амендментом); детерминизм XLA не запиннен
(NET_GATE_PROFILE=1 — вердиктные прогоны A5 идут отдельным профилем, ADR-013).

## Инцидент контура: C-040 на стенде во время пилота

Поведенческий страж AD-7 (`tools/check_gb10_single_load.py`) на стенде дал FAIL
в момент пилота: **две модельные нагрузки** — пилот (16,6 ГиБ GPU на старте) и
`llama-server` llm-platform (20,6 ГиБ GPU). llm-platform грузит модель по
запросам и отъедает пул сверху; при росте пилота это риск earlyoom-убийства.
Решение — за владельцем стенда: либо окна пилота = окна остановленной
llm-platform, либо принять риск осознанно. Зафиксировано как находка, прогон не
прерывался.

## RL-стадия: решение владельца 2026-10-04 (ADR-022)

Зафиксировано в `docs/adr/ADR-022` (коммит `b22f4e3`):
RL-стадия исполняется **на самом Spine AI/ML** — среда и верификатор = arch-ml
на GB10 (train/prod-харнесс идентичны, TITO); онлайн-синтез сред раундами ~300
задач (FrogNano, arXiv 2609.07925) на детерминированном мутаторе
`env/corruption.py` (AD-4); двусторонняя валидация задач + коридор pass-rate
[10%, 90%]; reward-цепочка Laguna (parse-error −0.1, anti-give-up −0.1,
таймаут 0.0) поверх формулы env v1; CISPO — флагом-абляцией к схеме базы
(ADR-005); гейты здоровья RL (энтропия/KL/clip/pass-rate) по
`rl-health-check` с перекалибровкой на 1B; анти-reward-hacking: скрытый
ротируемый holdout, раннер без сети, sha256 constraints до вердикта, post-hoc
review траекторий вне награды. Precondition калибровки среды (ENVIRONMENT-V1
§10) в силе.
