## 8. Решения по открытым вопросам финального контракта харнесса (архитектор, ~07:20 МСК)

1. **Дельта C — допуск и tracer-leak (решение для следующей дельты):** сравнение eager-loop-захвата со сканом — структурная эквивалентность двух реализаций, не числовой гейт; в том же файле уже действует прецедент `_SCAN_FORM_ATOL = 1e-4`. Решение: `allclose` с `atol=1e-4` (константа рядом с прецедентом, комментарий с замером 3.526e-5 и датой), проверка форм/NaN — строгая. Утечка трейсера (`test_t_b4_captured_inputs`) чинится **в тесте**: захват выносится из тела `lax.scan` в возвращаемые значения (aux/carry) либо снимается снаружи по итогам скана; `net/` не трогается. Если эквивалентность требует захвата внутри скана — это уже дельта в `net/` и отдельный ADR.
2. **Fitness/meta:** закрыто — C-005/C-036 и мета-тест зелёные с `d075e34` (ратификация выше); сущность `model/ADR-024` создана архитектором для симметрии с ADR-023 (trace_check PASS).
3. **SFT-аудитор:** семантика структурного распознавания тегов (начало строки) подтверждается — она соответствует фактическому формату `sft_train_v12` (chat-сентинелей в наборе нет; прежний черновик с сентинелями давал ложную сатурацию exit 2). Измеренные доли дефектов (9.6% / 10.6% / 1.5%) входят в карточку нормализованного набора v13 при сборке (§8.1); до тех пор носитель числа — настоящий документ.
