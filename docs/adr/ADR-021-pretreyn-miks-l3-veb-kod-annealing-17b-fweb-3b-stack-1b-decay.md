# ADR-021. Претрейн-микс L3: веб+код+annealing

- Date: 2026-09-26
- Status: **Accepted** — решение владельца 26.09.2026 (выбор «Веб+код+annealing» из четырёх пакетов:
  чистый FineWeb-Edu / веб+код+annealing / En+Ru+код / многократный annealing).
- Маршрут: Standard (data_contract). Бюджет прежний: 20B токенов, ≈97 H800-ч, ≈$200 (ADR-001/004).
- Приватные компоненты E/K/D/S (ADR-020) в претрейн НЕ входят (AD-6); их место — пост-трейн/CPT
  на собственном железе.

## Decision

Микс претрейна скелета L3, три шарда, все — публичные с лицензией, карточкой и шард-хешами (ADR-004):

| Шард | Источник | Объём | Назначение |
|---|---|---|---|
| W | FineWeb-Edu (en, edu-фильтр) | ~17B токенов | базовый язык/знания |
| C | The Stack v2 — подмесь разрешённых лицензий (Python/Rust/Go/JS/шелл-конфиги) | ~3B токенов | код-компетенция под агентную ось |
| Q | decay/annealing-фаза: ~1B токенов на сужённом высококачественном миксе (топ-фильтр W + кодовые примеры с тестами) | ~1B токенов | финальное качество (WSD: decay на качественной выборке) |

- Расписание: однофазный счётчик ~19B (W+C в пропорции ~85/15) → decay-фаза ~1B на Q.
- Токенизатор — собственный BPE 160K (без изменений); упаковка 8K (`net/data.py`).
- Скачивание/подготовка: FineWeb-Edu и The Stack v2 (HF), потоковая обработка, дедуп на уровне
  документов, карточка с sha256 шард-файлов до запуска претрейна. Целевое размещение —
  `~/gb10-shared/datasets/axiom-pretrain-l3/`, в репо — симлинки (C-032/C-033).

## Alternatives

- **Чистый FineWeb-Edu:** минимальный пайплайн, но код-компетенция остаётся на пост-трейн — хуже
  для оси победы при той же цене — отклонено.
- **En+Ru+код:** ближе к русскоязычному контуру, но качественная фильтрация русского публичного —
  отдельная трудоёмкая задача; домен русского закрывается пост-трейном (K/D/S) — отклонено, вернуть
  при смене языковой политики владельцем.
- **Многократный annealing:** максимум качества за усложнение пайплайна и выход из бюджета ≈$200 —
  отклонено; вернуться, если владелец поднимет бюджет.
- **Приватные компоненты в претрейне:** AD-6 (аренда = публичное) — отклонено (см. обсуждение 26.09).

## Consequences

Positive: ось победы (агентные/код-задачи с фитнес-гейтом) поддержана составом; decay-фаза —
стандартный прирост финального качества без изменения бюджета; карточка из 3 шарда — простой
пиннинг (AD-4). Negative: ~80 ГБ загрузок на gb10-shared (проверить свободное место до старта);
подготовка кодового шарда (лицензионный фильтр The Stack) — самая трудоёмкая часть пайплайна;
пропорция 85/15 — стартовая гипотеза, корректируется только до запуска претрейна. Reversibility:
до запуска претрейна — полностью обратимо (пересобрать микс); после — невозвратно (бюджет
сожжён), поэтому карточка и хеши фиксируются ДО запуска.

## Reversibility

До запуска претрейна микс пересобирается бесплатно; после — необратимо (бюджет). Гейт: карточка
+ хеши + смета (C-041) — блокирующие условия старта.
