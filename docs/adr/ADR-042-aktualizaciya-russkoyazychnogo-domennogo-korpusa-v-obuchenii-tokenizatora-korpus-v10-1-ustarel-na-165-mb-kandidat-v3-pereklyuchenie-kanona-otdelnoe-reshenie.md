# ADR-042. Актуализация русскоязычного доменного корпуса в обучении токенизатора

- Date: 2026-10-08
- Status: Accepted

## Context

**Что уже сделано (проверено, не гипотеза).** Русский доменный корпус **уже влит** в обучение
токенизатора: `tools/bpe_train_ru.py` обучает byte-level BPE 160K, добавляя поток **R** —
`cpt_corpus_v10.1.txt` (`sha256 1765628e…`, **299 141 131 байт, 923 061 документ**) с
переприсэмплом `--ru-oversample 3`. По манифесту `tokenizer-v2/tokenizer-manifest.json`:
`char_share 0.229`, `chars_effective 637 899 540`. Токенизатор **v2 (`16e4a5325f38df9d`**,
обучен 2026-10-04) — именно он стоит в претрейн-прогоне (лог: `токенизатор=16e4a5325f38df9d`).

**Эффект измерен** (проба на 400 000 символах доменного текста, `tokenizers` + реальные
`tokenizer.model` обеих версий):

| Токенизатор | Токенов | Симв/токен |
|---|---|---|
| v1 «канон» (`500f80237b3bd0fb`) | 177 184 | 2.26 |
| v2 RU-домен (`16e4a5325f38df9d`) | **86 258** | **4.64** |

То есть доменное упражнение выполнено и даёт **×2.06** по длине. Причина, по которой оно
понадобилось, зафиксирована в `tools/bpe_train_ru.py`: в каноническом словаре `500f8023`
кириллицы практически нет, русский разбирался до байтов (1.5–1.9 симв/токен), и доменная
CPT-стадия платила 3–4-кратный налог по длине.

**Чего не хватает сейчас.** Корпус **отстал от домена**: с 25.08.2026 (дата v10.1) доменный
источник вырос.

| Источник | Объём | В корпусе v10.1 |
|---|---|---|
| `~/library/concepts` — всего | 349 549 `.md`, **959.6 МБ** | частично (299 МБ) |
| `~/library/concepts` — новее 25.08 | **94 041 файл, 165.1 МБ** | **нет** |
| `~/library/distillate` | 83 МБ | нет |
| `~/library/cpt_corpus/clean` | 7.9 МБ | нет |

Билдер корпуса v10.1 в доступных местах не сохранился (найдены только ссылки: `ADR-020`,
`tools/bpe_train_ru.py`, отчёт `handoff_oxalpha_v10.1.md`) — корпус предстоит собирать заново
детерминированным скриптом.

**Цена вопроса.** Токенизатор — пиннованный канон (`AD-4`/`AD-11`, `net/config.json:tokenizer_hash`).
Смена словаря означает **перепозначение** всех токенизированных данных (`tokens-v2` → `v3`) и
затрагивает идущие/запланированные прогоны претрейна и CPT. Поэтому актуализация корпуса и
переключение канона разделяются: собрать и измерить кандидата — дешево и обратимо; переключить
канон — отдельное решение владельца с ценой перепозначения.

## Decision

1. **Собрать актуальный доменный корпус** детерминированным скриптом
   `tools/build_domain_corpus.py` тем же контрактом, что v10.1 (markdown-концепты; документ =
   абзац, разделитель `\n\n`), с полным покрытием домена: `library/concepts` (все `.md`),
   `library/distillate`, `library/cpt_corpus/clean`. Артефакт снабжается карточкой и манифестом
   (`sha256`, `bytes`, `docs`, `chars`, порядок обхода, seed) — по образцу
   `tokenizer-manifest.json`. Приватные тексты в git **не попадают** (C-032/C-033, AD-6):
   в репозиторий — только карточка/манифест и симлинк.
2. **Обучить кандидата v3** через `tools/bpe_train_ru.py` с новым корпусом (contract тот же:
   vocab 160000, byte-level, спецтокены `<pad> <bos> <eos> <|code|>` + 256 байтовых,
   `--ru-oversample 3`), **не меняя канон v2**: артефакт `tokenizer-v3` в стороне.
3. **Измерить кандидата на обеих сторонах**: (а) RU — симв/токен и токенов на тот же
   доменный holdout (эталон: v2 = 4.64, v1 = 2.26); (б) EN — на англоязычном holdout (W), чтобы
   убедиться, что усиление RU не деградировало английский; (в) `round_trip` = 1.0. Замер —
   скриптом, числа — в evidence.
4. **Переключение канона — отдельное решение владельца** (новый ADR или правка `net/config.json`
   с обновлением `tokenizer_hash`). Условие допуска к переключению: RU-выигрыш ≥ +15% без
   деградации EN более 2% и без потерь `round_trip`.
5. Прогон обучения — на GB10 **обязательно с `XLA_PYTHON_CLIENT_MEM_FRACTION`** (ADR-041) и
   префлайт-гейтом; конкуренция за GPU с чужими прогонами — запрещена.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---|---|---|
| **A. Актуальный корпус + кандидат v3 + замер, канон v2 не трогаем** (принято) | Домен актуализирован; выигрыш измерен до переключения; обратимо; идущие прогоны не затронуты | Требуется написать билдер заново (v10.1 не сохранился); переключение отложено |
| B. Оставить как есть (v2 на корпусе 25.08) | Ноль работы | Домен отстал на 165 МБ (17% объёма, +55% к корпусу); новые морфемы сентябрьского домена словарю недоступны — доменный налог по длине сохраняется |
| C. Поднять `--ru-oversample` у того же v10.1 (без обновления корпуса) | Одна строка | Не добавляет новых кириллических морфем: их нет в корпусе. Рост доли без роста покрытия — риск задавить английские мерджи без выигрыша |
| D. Сразу переключить канон на v3 с перепозначением данных | Экономия одного цикла решения | Дорого и рискованно: перепозначение всех данных, остановка/сброс идущих прогонов — **до** того, как выигрыш измерен. Нарушает «evidence на гейте, а не после» |

## Consequences

### Positive

домен актуализирован и измерен; кандидат v3 существует как проверяемый
артефакт; канон и идущие прогоны не затронуты; переключение — информированное решение с ценой.

### Negative

(1) обучение кандидата занимает GPU ~16–20 мин (у v2 `elapsed_s`
= 941.8 при 4 ГБ выборки) — при чужой нагрузке ждём; (2) сборка корпуса читает 350 тыс.
приватных файлов — операция на диске, десятки минут; (3) риск деградации английского при
усилении RU-потока — закрывается замером (б) из п.3; (4) билдер придётся восстанавливать
(исходный утерян) — есть риск не воспроизвести фильтры v10.1, поэтому сравниваем v3 с v2 на
одном holdout, а не «объём корпуса»; (5) переключение канона, когда до него дойдёт, потребует
перепозначения данных — цена не входит в эту дельту и будет предъявлена отдельно.

## Reversibility

**Полностью обратимо, цена низкая.** v3 — кандидат в стороне; канон v2 и `tokens-v2` не
затрагиваются. Откат = удалить артефакты кандидата и билдер (один revert-коммит). Корпус —
приватный артефакт на диске, из репозитория не удаляется (там только карточка/манифест).
Необратимых миграций нет.
