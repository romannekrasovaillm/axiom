# ADR-044. Поток S: скиллы и методики библиотеки плагинов в корпусе обучения токенизатора

- Date: 2026-10-08
- Status: Accepted

## Context

**Требование владельца (08.10.2026):** «разбавь обучение токенизатора скиллами из моей
библиотеки плагинов».

**Обследование (измерено).** Библиотека: `/home/roman/experiments/agents/0710-ariadna/plugins`
— **103 МБ, 203 плагина**. Состав по типам: **`md` 3681 файл = 27.0 МБ** (текстовый слой),
`py` 5.4 МБ, `sh` 0.4 МБ, `json` 0.4 МБ, бинарь/архивы (`pack` 16.4 МБ, `zip`, `jpg`, `pyc`) —
служебное. Из md: **1912 `SKILL.md`** + субагенты (`agents/*.md`) + прочие методические
документы плагинов. Плюс managed-зона `~/.arch-ml/plugins` — 2.6 МБ, 91 `SKILL.md`.

**Профиль языка (выборка 3 МБ md):** **кириллица 70.1%, латиница 29.9%** — смешанная
русско-методическая речь с английскими идентификаторами (имена флагов, утилит, форматов).
Это ровно профиль тех документов Spine, с которыми модели предстоит работать (см. вопрос
владельца о русских Spine-доках), поэтому поток S ценен не объёмом, а **характером текста**.

**Формат.** `SKILL.md` = YAML-фронтматтер (`name`, `description` — триггеры и синонимы
запросов) + тело методики: процедуры, чек-листы, антипаттерны, команды, пути. То есть в
словаре появятся устойчивые доменные н-граммы: «вызови», «артефакт», «гейт», `--flag`,
`SKILL.md`, `handoff`, `spine`.

**Секреты.** Скан md по паттернам ключей (`sk-*`, `ghp_*`, `BEGIN … PRIVATE KEY`,
`api_key=…`) дал **0 совпадений**. Однако рядом лежат `json`-конфиги (в т.ч. MCP) и shell-
примеры, где секреты возможны — поэтому правило скраба (ADR-043) распространяется и на S.

## Decision

1. **Поток S входит в корпус обучения токенизатора** — как отдельный источник
   `tools/build_domain_corpus.py` (наряду с R — концепты, T — трейсы).
2. **Состав потока S — только текстовые методические слои:** `**/SKILL.md`, `**/agents/*.md`,
   прочие `*.md` внутри плагинов (README, описания), а также managed-зона `~/.arch-ml/plugins`.
   Исключаются: `*.py`, `*.sh`, `*.json*`, `*.pyc`, `*.pack`, `*.zip`, изображения, бинарь —
   код и служебные данные не являются методическим текстом и засоряют словарь.
3. **Обязательный скраб** (тот же `tools/axiom_ds/scrub.py`, что для T) **до** записи корпуса,
   fail-closed. Для S дополнительно: вырезать YAML-фронтматтер из тела (он служебный) либо
   оставлять его в счётчиках отдельно — на усмотрение реализации, но решение фиксируется в
   манифесте.
4. **Доля параметризована** (`--skills-share`, дефолт **≤0.10**): поток S мал (27 МБ против
   960 МБ домена R), и его задача — задать доменные н-граммы, а не занять выборку.
5. **Приватность:** производный корпус S на диск, в git — только манифест/карточка
   (C-032/C-033, AD-6). Пути библиотеки в карточке указываются как есть (репозиторий
   приватный), но тексты — нет.
6. **Прогоны — на GB10 с `XLA_PYTHON_CLIENT_MEM_FRACTION`** (ADR-041) и префлайт-гейтом.
7. Скиллы, попадающие в S, **не дублируются** в T (трейсы сессий тоже содержат цитаты
   скиллов) — дедупликация на уровне строк/абзацев с приоритетом S для методических блоков.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---|---|---|
| **A. Только текстовые методические слои (md) + скраб + доля ≤0.10** (принято) | Даёт ровно доменную смешанную речь; 70% кириллицы; чисто | 27 МБ — мал по объёму; требует дедупа с T |
| B. Включить всё содержимое плагинов (103 МБ, с py/json/ш) | Полнота | Код, MCP-конфиги (риск секретов), `pack`-архивы, изображения — мусор в словаре; растёт риск утечки |
| C. Только `SKILL.md` (без субагентов и README плагинов) | Минимум шума | Теряем описания субагентов и плагинов — а это тоже доменная методическая речь |
| D. Не включать скиллы | Ноль рисков | Отклонено владельцем; теряется самый релевантный доменный профиль (методики контура) |

## Consequences

**Положительные:** словарь получает доменные н-граммы методической речи (гейт, артефакт,
handoff, `SKILL.md`, флаги CLI) в смешанном RU/EN регистре; объём мал — доля легко
контролируется; секретов в md не обнаружено (риск ниже, чем у T).

**Отрицательные (честно):** (1) YAML-фронтматтер и повторяющиеся шаблоны скиллов могут
усилить служебные токены (лечится вырезанием фронтматтера и дедупом); (2) 27 МБ — статистически
мало для изменения словаря, эффект может оказаться в пределах шума: это проверяется замером,
а не предполагается; (3) пересечение с потоком T (цитаты скиллов в трейсах) — нужен дедуп;
(4) библиотека живёт вне репозитория и меняется — манифест обязан фиксировать `sha256` и
снимок состава, иначе воспроизводимость теряется.

## Reversibility

**Обратимо, цена низкая.** Поток включается флагом (`--skills-*`); отключение = пересборка
корпуса без S. Откат решения — пометка ADR Superseded. Данные вне репозитория. Необратимых
миграций нет.
