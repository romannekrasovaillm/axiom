# Рубричная оценка решений — 2026-10-09

**Чем:** рубрики Spine (`arch-be 0.3.16`, assets `adr_quality`, `adr_spine_consistency`, `nfr_mechanism_fit`), судья — `deepseek-flash`, 3 сэмпла на критерий.
**Как:** через MCP-судью (`rubric_evaluate`); CLI-путь (`arch-be rubric run`) из shell недоступен — провайдер не получает ключ (`нет API-ключа: установите DEEPSEEK_API_KEY`), поэтому автоматические `reports/rubric/*.json` для составляющей `decision_quality` этим способом не создаются.
**Охват:** `arch-be rubric handover` — принятых ADR **36, без свежего отчёта 36** (рубричная оценка в кейсе ранее не велась ни разу; поэтому `decision_quality` в едином гейте стоит SKIP).

## Системный вывод (что менять в решениях, а не в рубрике)

1. **Expiry/условие пересмотра — общий пробел** (указан в 3 из 4 оценок). Внесено правкой: раздел «Пересмотр» добавлен в ADR-049, ADR-050, ADR-051 (дата/триггер + кто решает).
2. **Признак промаха** (`degradation_defined` 3/5): в ADR-050 введено правило остановки кампании с привязкой к датчику — если G1 не закрыт после трёх изолированных рычагов ИЛИ занятость GPU ниже 10% при 40%-цели, кампания останавливается и фиксирует потолок (сенсор S-027 `derived_mfu`, правило `C-046`).
3. **Рубрики — в практику новых решений**: каждый новый ADR кейса оценивается `adr_quality` + профильной рубрикой (для NFR-целей — `nfr_mechanism_fit`, для правок спайна — `adr_spine_consistency`). Оценка — до реализации (решение раньше кода).

## Долг контура (не закрыт)

- **36 принятых ADR без отчётов рубрик** → составляющая `decision_quality` в `[gate.required]` пока не включается (иначе вечный красный). Цена закрытия: прогон судьи по 36 документам × 3 сэмпла + независимость судьи (`judge_is_author`) — отдельное решение владельца; вариант «только для новых ADR» — политика, требующая поддержки `scope` в контуре.
- **Независимый второй судья** (E5.1) для наших ADR не привлекался: судья один (`deepseek-flash`), автор документа — архитектор-агент, а не та же модель, поэтому метка `judge_is_author` не ставится, но независимость ограничена одной моделью.
