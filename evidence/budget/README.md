# evidence/budget/ — сметы прогонов до запуска (AD-8)

Каталог хранит сметы как **артефакты**, а не как прозу: инвариант AD-8
(«стоимость прогона лимитирована до запуска») проверяется behavioural-стражем
**C-041** — `python3 tools/check_budget_gate.py --verify`.

Смета без прогона и прогон без сметы равнозначно недействительны: файл здесь
появляется только вместе с реальной оценкой, которую кто-то утвердил.
Отсутствие сметы — не «нет данных», а **блокировка запуска**.

## Контракт артефакта

Путь: `evidence/budget/<run-ref>.json`, где `<run-ref>` совпадает с полем
`run_ref` манифеста прогона (AD-4, `evidence/*-run-manifest.json`).
Имя файла — только буквы, цифры, `.`, `_`, `-`.

| Поле | Тип | Смысл |
|---|---|---|
| `run_ref` | строка | ссылка на прогон; совпадает с именем файла и с `run_ref` манифеста |
| `gpu_type` | строка | тип арендуемого GPU (кейс считает в H800) |
| `gpu_hours_estimate` | число > 0 | оценка прогона в GPU-часах |
| `usd_estimate` | число ≥ 0 | оценка стоимости, USD |
| `limit_usd` | число ≥ 0 | лимит, при превышении которого прогон останавливается |
| `budget_method` | строка | метод оценки; обязан ссылаться на калибровку AD-8 (arXiv 2412.19437, 343 TFLOP/s эффективных на H800) |
| `stop_rule` | строка | стоп-правило: «остановка после ближайшего чекпойнта при превышении лимита» |
| `created_at` | строка ISO-8601 | дата создания сметы; **строго раньше** даты прогона |
| `approved_by` | строка | кто утвердил смету |

Пример формы (не артефакт — иллюстрация контракта; лимит L3 ≤ $200 взят из
NFR-003, прогон A4 — `a4-skeleton`):

```json
{
  "schema": "budget-estimate/v1",
  "run_ref": "a4-skeleton",
  "gpu_type": "H800",
  "gpu_hours_estimate": 97,
  "usd_estimate": 200,
  "limit_usd": 200,
  "budget_method": "калибровка по arXiv 2412.19437: 343 TFLOP/s эффективных на H800",
  "stop_rule": "остановка после ближайшего чекпойнта при превышении лимита",
  "created_at": "2026-09-12T10:00:00+00:00",
  "approved_by": "<кто утвердил>"
}
```

## Генерация

```bash
python3 tools/check_budget_gate.py --estimate a4-skeleton \
    --gpu-hours 97 --usd 200 --limit-usd 200 \
    --approved-by <кто утвердил>
```

Запись атомарна. Без входных данных (`--gpu-hours`, `--limit-usd`,
`--usd`/`--usd-per-gpu-hour`, `--approved-by`) генератор завершается с
ненулевым кодом и **ничего не пишет**: выдуманная смета — фабрикация
доказательства. Существующая смета не перезаписывается без `--force`.

## Реестр прогонов

Страж без `--run-ref` требует сметы для прогонов, объявленных в
`evidence/README.md` (сейчас — A4 `a4-skeleton` и A5 `a5-rerun`), плюс для
каждого найденного манифеста прогона. Объявляя новый прогон, дополните реестр
`DECLARED_RUN_REFS` в `tools/check_budget_gate.py` — иначе у прогона не будет
ни сметы, ни требования.
