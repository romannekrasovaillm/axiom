# evidence/facts/ — записи фактов датчиков (ADR-036, дельта C1)

Один датчик — один файл `<S-id>.jsonl`, строки только дозаписываются. Запись
факта привязана к пину предмета (`subject`: git sha, sha256 конфига/токенизатора/
чекпойнта, датасет, прогон, хост, устройство) и несёт `prev_sha256` предыдущей
строки — правка истории обнаружима.

Пишет факты только датчик (`tools/sensors/**`); вердикт выносит предикат
утверждения (`tools/check_claims.py`) по реестру `model/claims.yaml`. Датчик,
которому недоступен предмет, пишет `status: unverified` с причиной в `note`, а
не подстановку (C-007). Проверка реестра и файлов: `python3 -m tools.sensors.probe`.

Каталог исключён из снапшота песочницы (`env/util.py`), поэтому гейт C-048
(`check_claims --evaluate`) — правило репозитория и внесено в `EXCLUDED_INFRA_RULES`
песочницы; C-047 (сверка деклараций реестров) исполняется в воркспейсе без сети.
