# Снимок механических гейтов кейса axiom — 12.09.2026

**Статус: промежуточный.** Это не закрытие A4: критерии 6 (экстраполяционный recall, `xfail`)
и 16 (цена 8K) на момент снимка не выполнены. Файл фиксирует то, что уже проверено механически,
чтобы результат не пересказывался заново.

**Пиннинг:** коммит `cc40092` (ветка `main` репозитория `spine-aiml`, каталог `кейсы/axiom`),
рабочее дерево чистое на момент прогона.

## 1. Fitness-гейт кейса

```
$ arch-be control check . --constraints CONSTRAINTS.yaml
Правил: 34, нарушений: 0 (error: 0, warn: 0)
Итог: PASS
```

Правила читаются из корневого `CONSTRAINTS.yaml` кейса (34 правила: 21 `must_contain`,
7 `each_file_must_contain`, 3 `command_succeeds`, 2 `must_not_contain`, 1 `file_exists`).
Три `command_succeeds` — лёгкие проверки артефактов (`find` по весам и большим файлам,
наличие `docs/adr/ADR-009-*.md`).

Замечание: в `evidence/README.md` этот же гейт описан как «зелёный, 31 правило» — расхождение
с фактическими 34. Документ поправлен вместе с этим снимком.

Отдельно: файл `.arch-handoff/CONSTRAINTS.yaml` (заготовка генератора пакетов, под `.gitignore`)
не читается YAML-парсером — некорректный отступ у первого элемента списка, строка 7. На гейт кейса
это не влияет (он читает корневой `CONSTRAINTS.yaml`), но при передаче пакета внешнему исполнителю
заготовка попадает в пакет и может быть принята за рабочие правила.
