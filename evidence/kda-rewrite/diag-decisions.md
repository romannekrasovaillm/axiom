# Решения архитектора по вопросам CE-диагностики (hr-16, 09.10.2026)

Контекст: декомпозиция CE добавлена (ноги `sec_ce_logits`, `sec_ce_softmax` = разность, `sec_ce_mtp` и обратные). Реальные числа ожидаются прогоном на GB10 (два прогона: fp32/bf16), который **отложен**: стенд занят параллельной работой линии-1 (их `pytest net/tests tools/tests`, 21+ мин, GPU 96%), префлайт-гейт ADR-041 корректно отказал в совмещении.

1. **Независимая softmax-нога — не делать сейчас.** Разностная (`sec_ce_ntp − sec_ce_logits`) достаточна для первого среза; если на прогоне разность утонет в шуме host-таймера, вернёмся к независимому проходу осознанно (он стоит лишней материализации logits).
2. **Математику MTP не менять.** Нога `sec_ce_mtp` даёт **цену** вклада, а не вердикт о пользе. Любое исключение/взвешивание MTP-лосса — отдельное решение (влияет на обучение), не в этой линии.
3. **`tools/profile_step.py` обновить** — он держит локальный список ног (`sec_kda…sec_backopt`) и новые CE/backward-ноги не рендерит; иначе диагностика есть в метриках, но не в отчёте прибора. Малая правка, отдельным шагом.
4. **Смена `AXIOM_COMPUTE_DTYPE` внутри одного процесса** — не поддерживать: dtype фиксируется на процесс (как в `compute_dtype.mode()`); при необходимости сравнить dtype — два отдельных прогона (что мы и делаем).
5. **Поля `metrics.jsonl` расширяются аддитивно** (существующие не переименованы) — подтверждаю; потребителей с пиннутым полным списком полей в репозитории нет, вне репозитория гарантировать не могу, поэтому правило — только аддитивные изменения.
6. **Красный гейт (ADR-010/013 + AD-7) — долг стенда, не дельта.** Подтверждаю: снимается операторским прогоном на GB10; на неисполнении этих правил вывод о дельте не строится (ADR-046 — SKIP-семантика).
7. **Параллельная дописка `evidence/facts/*`** (число находок secrets росло 611→671→731) — работа датчиков линии-1 в общем дереве. Не блокер; в коммиты не тащим.
8. **`everything_saveable` измерен: OOM 232.96 ГиБ** — шкала remat исчерпана вверх (подтверждение вывода ADR-049: предел — память устройства).
