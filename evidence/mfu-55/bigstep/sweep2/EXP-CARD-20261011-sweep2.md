# Карточка эксперимента: EXP-20261011-sweep2 (серия-2 кампании MFU-55)

- **id:** EXP-20261011-sweep2 · **дата:** 2026-10-11 · **автор:** архитектор (оператор стенда)
- **Гипотеза (по доказанным адресам, ADR-050 п.5 / ADR-053 Am.2):**
  1. Чанк KDA (дефолт 64 → 128 итераций скана на 8192) — главный генератор диспетчерской
     нагрузки; укрупнение чанка до 256-1024 сокращает число итераций While в 4-16 раз.
  2. XLA 0.11.2 command buffers для WHILE/CONDITIONAL/DOT/COMPUTE (+ --xla_gpu_command_buffer_unroll_loops)
     переводят сканы в GPU-side исполнение — сокращение 85k запусков ядер/шаг.
  3. B=4 OOM (HLO-пик 109.38 GiB) адресуется мельчайшим CE-чанком (2048).
- **Окружение:** как EXP-20261010-bigstep (0.11.2, GB10, ce4096, remat none, gc full, at=2, mem 0.96),
  отличается только чанк/CB/CE по клетке; метрика — mfu_pct в процентах, медиана шагов ≥ 2.
- **Клетки:** c064/c128/c256/c512/c1024_B1 (лестница чанка) · cbunroll/cb_c064_B1 (CB) ·
  cbunroll/cb_c{best}_B2 + c{best}_B2 (комбинации) · b4_ce2048 (ремедио OOM).
- **Ожидания (MDV):** c128 ≥ 1.45% · c256 ≥ 1.55% · cbunroll ≥ 1.6% · комбинация — цель S1 ≥ 3% (977 ток/с).
- **Стоп-критерии:** 3 отказа подряд; таймаут клетки 2400 с; бюджет $5/клетка (AD-8).
- **Сопоставимость:** сравнивать только одинаковые chunk/ce/CB/B; условия — часть результата (ADR-050 Am.2).
