# Цикл-25 (опережающий) — измеренные потолки GB10 под цель G4 = 55 % MFU

- Дата: 19.10.2026, стенд GB10, JAX 0.11.2, `tools/c25-peak-probe.py`.
- Замер: матмул 8192³, fp32-аккумуляция, 8 итераций после прогрева; копия 8192² bf16.

| класс | измерено | примечание |
|---|---:|---|
| bf16 | **88.8 TFLOPS** | конвенция ADR-050 использует *объявленные* 98.2 (завышение ~10 %) |
| fp16 | 83.8 TFLOPS | — |
| **fp8 e4m3** | **131.7 TFLOPS** | ×1.48 к bf16 (не ×2: потребительский Blackwell) |
| копия | **416.9 ГБ/с** | выше предположенных 273 ГБ/с |

## Что это значит для 55 %

- G4 = 55 % от 98.2 = **54.0 TFLOPS / 17 917 ток/с / 1.83 с на шаг** (32768 токенов).
- Текущий лидер: 1 139.2 ток/с (3.50 % по конвенции; **3.87 % от измеренного пика**),
  шаг 28.76 с ⇒ нужен **×15.7**.
- Реальные FLOPs шага ≈ параметрические 98.8 TFLOP + T²-внимание ~15 TFLOP ≈ **114 TFLOP**.
  На 1.83 с это **62 TFLOPS устойчиво** = 70 % измеренного bf16-пика (или 47 % fp8-пика).
- Сегодняшняя реальная утилизация: 114 / 28.76 = **3.96 TFLOPS (4.5 % пика)**.

**Вывод.** 55 % — не «ещё один кернел», а смена класса:
1. **FP8-обучение** (E4M3, скейлинг, стабильность; ×1.48 к пику) — обязательное условие:
   на bf16 требуется ~70 % устойчивой утилизации, что для end-to-end шага
   обучения практически недостижимо;
2. **перестройка рантайма/фьюзинга** (хост-цена, батчи, персистентные кернелы) —
   второй множитель ×2+;
3. промежуточные гейты: G2 10 % (11.7 с, 9.7 TFLOPS real), G3 20 % (5.9 с, 19 TFLOPS).
