# Локализация 191 488 микро-ядер: результата и вердикт (10.10.2026)

## Что найдено

**Микро-ядра `(1,1,1)×128, regs=16` — это `command_buffer`-thunk'и XLA.**

Доказательство — NVTX-разметка в профиле (`NVTX_EVENTS`, 1 118 254 событий): имена вида
`Thunk:#hlo_op=command_buffer_565#`, `command_buffer_616#`, `command_buffer_3535#`, `command_buffer_3508#` —
**тысячи различных `command_buffer_NN`, каждый запускается ~3 800 раз** за 120 с. Количество совпадает с числом `cuLaunchKernel` (191 417), то есть запуск command buffer'ов идёт через хостовый `cuLaunchKernel` (30.2 с = 25% окна).

Микро-ядра распределены **равномерно** по времени (~4–6 тыс. каждые 2 с) — то есть рождаются в каждом слое, а не в отдельной фазе.

## Проверка гипотезы «отключить command buffers»

`XLA_FLAGS=--xla_gpu_enable_command_buffer=` (пустой список = выключено), тот же конфиг, 4 шага:

| Конфигурация | ток/с | шаг, с | MFU |
|---|---|---|---|
| база 0.11.2 (CB включены, по умолчанию) | 410.7 | 19.93 | 1.26% |
| **CB отключены** | **400.2** | **20.47** | **1.23%** |

**Гипотеза опровергнута:** отключение command buffers не ускоряет, а слегка **замедляет** (−2.5%). То есть command buffers — не источник накладных расходов, а **следствие мелкой структуры графа**: XLA группирует множество мелких операций в command buffer'ы, и их много потому, что операций много, а не наоборот.

## Вывод

1. **Диспетчеризацию нельзя снять флагом.** 25% времени хоста уходит на запуск ~32 тыс. единиц работы на шаг, но это отражение **гранулярности графа**: чтобы снять накладные, нужно **укрупнить работу**, а не менять способ её запуска.
2. **Направление подтверждается клетками**: L1 dense MLP даёт 59.9% MFU при 8192 токенах и **65.2% при 32768** — то есть рост масштаба работы (токенов на шаг) прямо повышает MFU.
3. **KDA/MLA-кернелы (Mosaic/Triton) в этой картине вторичны**: их формы малы, а вклад фаз — единицы процентов; укрупнение батча даёт эффект на порядок больше.
4. **Практический приоритет:** крупный батч токенов (ADR-032: 256K токенов/шаг) как основной рычаг MFU; всё остальное (кернелы, флаги) — после того как формы станут крупными.
