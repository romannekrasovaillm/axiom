- **Binds**: данные и траектории ↔ аренда GPU ↔ внешние API
- **Prevents**: вывоз приватных данных на чужую инфраструктуру ради дешёвого baseline
- **Rule**: на аренду — только обезличенные/публичные датасеты с карточкой и хешем; задачи приватного домена не уходят во внешние API; baseline K3 на приватных данных — только локально.
- **Статус**: [PROPOSED]
