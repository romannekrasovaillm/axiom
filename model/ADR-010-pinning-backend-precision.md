Приёмочные тесты сети (`net/tests/conftest.py`) пиннят явно: `jax_default_matmul_precision = "highest"` (оракулы проверяют алгоритм, а не политику точности железа; порог критерия 2 остаётся 1e-4), бэкенд выбирается явно и печатается в заголовке прогона (`jax.devices()`), запуск с GPU обязателен для гейта A4 — `test_10_gpu_smoke` даёт PASS, а не SKIP, при отсутствии GPU в гейтовом профиле фиксируется FAIL с внятным сообщением. Основание — замер 12.09.2026: критерий 2 на GPU при дефолтной политике даёт 3.37e-04 (порог 1e-4), при `high`/`highest` — 1.2e-07; на CPU — 6e-08 при любой политике; один и тот же коммит давал разные вердикты сьюта в зависимости от `LD_LIBRARY_PATH` (прогоны 18:07 и 19:15). Принято владельцем 2026-09-13. Отвергнуто: измерение на дефолтном окружении (вердикт не механический — нарушение AD-2/AD-4) и пиннинг только бэкенда с раздвоением порога критерия 2.
