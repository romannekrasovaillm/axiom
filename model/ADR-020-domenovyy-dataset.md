axiom-domain-ds-v1 — четыре компонента: E агентные эпизоды (верифицированные механически,
fail-closed), K концепты (фильтр по домену), D дистилляты, S скиллы (фильтр по ML-плагинам).
Пайплайн: скраб → эпизодизация → верификация → дедуп (точный + MinHash, межкомпонентный) → карточка.
Приватный (AD-6), на аренду не уходит. Претрейн-наполнение сессиями отклонено.
