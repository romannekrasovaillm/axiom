Чанковый KDA переписывается на WY/UT-форму Kimi Linear (arXiv 2510.26692 §3.1):
перенос состояния S матмулами по чанкам, внутри чанка WY-коррекция C×C —
вместо associative_scan по моногруппе переходов (мемори-BOUND, 41,5 ГиБ/слой).
Лестница: pure-JAX → Pallas/Triton → FlashKDA-FFI (с амендментом ADR-017).
Флаг kda_impl, паритет allclose, однократный числовой сброс базасов.
KPI: ток/с (медиана стабильного окна ≥20 шагов, §3.1), базис 80–86,
цель ≥800 (10×) → далее ≥10% MFU. Батч: микробатч + накопление до 256K
токенов/шаг оптимизатора, контрольная рука LR. Директива владельца 05.10.
