Среда по рецепту базы: харнесс как набор конфигурируемых модулей, награда по финальному состоянию среды, публичный и скрытый верификаторы, изоляция агента от верификатора. Verifier v1 — fitness-правила репозитория; домен конкретизирован ADR-006 (архитектурные задачи собственного контура: вердикт — гейты fitness/trace/spine arch-ml без деградации; precondition запуска RL — кальбровочный прогон K3); контракт прогона (task spec, runner, run manifest) описывает ADR-002. Полная спецификация environment v1: `docs/specs/ENVIRONMENT-V1.md` (task spec, верификаторы, плотная награда, лесенка, кальбровка, критерии приёмки). K3 и собственные кандидаты проходят один и тот же контракт; holdout-набор ротируется, обучение по нему запрещено.
