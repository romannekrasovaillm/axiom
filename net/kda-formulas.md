## 1. KDA — Kimi Delta Attention (§2.1.1)

### 1.1 Рекуррентная форма (Eq. 1, :229)

```
S_t = (I − β_t k_t k_t^⊤) Diag(α_t) S_{t−1} + β_t k_t v_t^⊤
õ_t = S_t^⊤ q_t
```

Нотация: `x_t ∈ R^d`, `q_t, k_t ∈ R^dk`, `v_t ∈ R^dv`, рекуррентное состояние `S_t ∈ R^{dk × dv}`.
`α_t ∈ (0,1)^dk` — канальный (per-dimension) одношаговый retention-фактор; `β_t ∈ (0,1)` —
сила записи delta-rule. Порядок операций: сначала канальный decay `Diag(α_t) S_{t−1}`,
затем delta-забывание `(I − β_t k_t k_t^⊤)` и запись `β_t k_t v_t^⊤`. Выход — `S_t^⊤ q_t`.

### 1.2 Пер-головная параметризация (Eq. 2, :235–245)

```
q_t^h, k_t^h = L2Norm(Swish(ShortConv(W_{q/k}^h x_t))) ∈ R^dk
v_t^h        = Swish(ShortConv(W_v^h x_t))            ∈ R^dv
β_t^h        = Sigmoid(W_β^h x_t)                      ∈ (0,1)
z_t^h        = W_α^↑ W_α^↓ x_t + b_α^h                 ∈ R^dk
```

Q/K/V-проекции проходят ShortConv, затем Swish; Q и K дополнительно L2-нормируются
(:247). Low-rank-проекция `W_α^↑ W_α^↓` и per-head смещение `b_α^h ∈ R^dk` дают
мелкозернистый decay-logit `z_t^h` для каждого канала ключа (:247–248).

### 1.3 Чанкированная (chunkwise) форма (Eq. 3–4, :254–277)

Размер чанка `C`. Матрица `S[t] ∈ R^{dk × dv}` — состояние, входящее в чанк `t`.
Для позиций `1 ≤ i ≤ j ≤ C` канальный кумулятивный decay:

```
γ[t]^{i→j} = Π_{r=i}^{j} α_r[t],    γ[t]^{1→r} — кумулятивный decay от начала чанка
```

`Γ[t]^{1→C} ∈ R^{C×dk}` складывает `γ[t]^{1→1}, …, γ[t]^{1→C}` по строкам (:261–264).
UT-преобразование даёт `U[t]`, `W[t]`, из которых pseudo-value `Ṽ[t] := U[t] − W[t] S[t]` (:266).
Все выходы чанка считаются параллельно:

```
A[t] = Tril((Q[t] ⊙ Γ[t]^{1→C}) (K[t] / Γ[t]^{1→C})^⊤)
O[t] = (Γ[t]^{1→C} ⊙ Q[t]) S[t] + A[t] Ṽ[t]
       └──── inter-chunk ────┘   └── intra-chunk ──┘
```

`Tril(M)` обнуляет строго верхнетреугольные элементы, диагональ сохраняется — маска
каузальности внутри чанка (:279–283).

### 1.4 Lower-bounded decay (Eq. 5, :326–330)

Kimi Linear использовал неограниченный negative-Softplus `g_t^h = −e^{A_h} Softplus(z_t^h) ∈ (−∞,0)`.
K3 заменяет его масштабированной сигмоидой, ограничивающей log-decay снизу:

```
g_t^h = g_min · Sigmoid(e^{A_h} z_t^h) ∈ (g_min, 0)^dk
α_t^h = exp(g_t^h)              ∈ (e^{g_min}, 1)^dk
```

`A_h` — обучаемый per-head log-scale (инициализация `A_h = 0`), `g_min = −5` фиксирован.
При `g_min = −5` каждый retention-фактор `α_{t,j}^h > e^{−5} ≈ 6.7×10^{−3}`, кумулятивный
log-decay за 16-токенный тайл лежит в `(−80, 0)` — реципрокный рескейл < `e^80`, что в
пределах BF16 (:332–339).

### 1.5 Full-rank output gate (Eq. 6, :345)

```
y_t = W_o [Sigmoid(W_g x_t) ⊙ RMSNorm(õ_t)]
```

После head-wise RMSNorm над рекуррентным выходом — data-dependent output gating.
K3 заменил low-rank gate Kimi Linear на полноразмерный `W_g` (:342–345).

## 2. Gated MLA (§2.1.2, :347–370)

MLA сжимает KV-представление токена в латент `c_t = W_c x_t` (:348–351); content-ключи и
значения восстанавливаются обучаемыми up-проекциями при вычислении внимания. Кэшируется
только `c_t`.

K3 применяет **NoPE** ко всем MLA-слоям: явного позиционного кодирования в q/k нет (:353–357).
Gate — полноразмерный, канальный (Eq. 7, :360):

```
y_t = W_o [Sigmoid(W_g x_t) ⊙ õ_t]
```

где `õ_t` — ungated выход MLA. Выход внимания держится в FP32 на обучении для коррекции
смещённой ошибки округления flash-attention (:367–370).

## 3. AttnRes — Attention Residuals (§2.2, :372–414)

Полная форма (Eq. 8–9, :380–391): для слоя `l` обучаемый pseudo-query `q_l = w_l ∈ R^d`,
ключи/значения:

```
k_i = v_i = h_1 (i=0);  f_i(h_i) (1 ≤ i ≤ l−1)
```

где `f_i(h_i)` — выход слоя `i`, `h_1` — эмбеддинг токена. Softmax-ядро
`ϕ(q,k) = exp(q^⊤ RMSNorm(k))` (:386); RMSNorm не даёт слоям с большим выходом доминировать:

```
α_{i→l} = ϕ(q_l,k_i) / Σ_{j=0}^{l−1} ϕ(q_l,k_j),   h_l = Σ_{i=0}^{l−1} α_{i→l} · v_i
```

Block-форма (Eq. 10, :396–412): `L` слоёв делятся на `N` блоков по `S = L/N` слоёв.
Внутри блока выходы слоёв редуцируются суммированием: `b_n^i = Σ_{j∈B_n, j≤i} f_j(h_j)`,
`b_0 = h_1`. Для i-го слоя блока `n`:

```
V = [b_0, b_1, …, b_{n−1}]^⊤                        если i = 1 (первый слой блока)
V = [b_0, b_1, …, b_{n−1}, b_n^{i−1}]^⊤             если i ≥ 2 (последующие слои)
```

У K3: 8 блоков по 12 слоёв, последний блок частичный, 9 блоков с учётом эмбеддинга (:413–414).

## 4. Stable LatentMoE (§2.3, :416–589)

LatentMoE отделяет полную ширину модели от ширины routed-экспертов: shared-эксперты —
полноширотный путь, routed-эксперты работают в компактном латентном пространстве `ℓ`.
K3: 896 routed, 16 активных, Ns = 2 shared (:421–424, :472).

Форма (Eq. 11, :462–467):

```
u = Σ_{i∈T_k(x)} p_i E_i^{routed}(W_↓ x)
y = Σ_{j=1}^{Ns} E_j^{shared}(x) + W_↑ RMSNorm(u)
```

`u ∈ R^ℓ` — агрегированное routed-представление, `p_i` — вес роутера (по QB ниже).

### 4.1 Normalized LatentMoE (§2.3.1, :474–479)
RMSNorm между агрегацией экспертов и up-проекцией — снижает чувствительность routed-ветви
к вариации масштаба.

### 4.2 SiTU-GLU (Eq. 12, :481–498, :535–537)

```
SiTU-GLU(x) = [β_1 tanh(W_g x / β_1) ⊙ Sigmoid(W_g x)] ⊙ [β_2 tanh(W_u x / β_2)]
```

`softcap(x, β) = β tanh(x/β)` применяется к линейному фактору Swish-гейта и к up-ветви.
Гиперпараметры K3: `β_1 = 4` (gate), `β_2 = 25` (up) (:535). Обе ветви ограничены,
`|f(x)| ≤ β_1 β_2 = 100` (:452–453).

### 4.3 Quantile Balancing (Eq. 13–14, :541–589)

Роутер: `s_i = Sigmoid(W_r x_i)`, выбор `T_i = argtopk(s_i + b)`, веса `p_{i,j} = s_{i,j}/Σ_{r∈T_i} s_{i,r}`
(:545–547). Bias `b` не входит в `p_{i,j}` — регулирует dispatch, не меняя веса смеси.
Обновление QB (Eq. 14, :578–583):

```
b̂_j^{(t+1)} ← −quantile_{1−k/n}(s_{:,j} − α^{(t)})
b^{(t+1)}  ← b̂^{(t+1)} − mean(b̂^{(t+1)})
```

`α_i^{(t)}` — cutoff из Top-(k+1) маршрутизации (:558–561). Обновление действует со следующего
шага (каузальность), на инференсе bias заморожен (:588–589). Практическая оценка — гистограммой
маргиналов через all-reduce (:592–598).

## 5. Per-Head Muon (§2.5, :661–671)

Muon [53] — оптимизатор матричных параметров. Per-head вариант: Newton–Schulz-ортогонализация
применяется не к полным Q/K/V-проекциям, а к блокам моментных матриц по оси голов — выравнивает
масштаб обновлений между головами (:663–669).
